# Rights and distribution scope

The recovered original research materials do not contain an explicit outbound open-source license. This handoff does not invent a permissive grant or change ownership. Public availability alone is not an open-source license; obtain the owner's license decision if reuse licensing is intended.

Third-party papers/full-text extractions are not distributed. Bibliographic facts, original comparisons, URLs and available SHA-256 records are retained. Public download access does not establish redistribution rights. Original synthetic model inputs, generated certificates, scientific code and original-work figures are included as research evidence.

Dependency packages are not bundled. Their individual upstream licenses apply. ANDES's upstream project states GPL-3.0-or-later (https://github.com/CURENT/andes/blob/master/LICENSE); motulator's upstream project states MIT (https://github.com/Aalto-Electric-Drives/motulator/blob/main/LICENSE), checked 2026-10-07. Version-specific license metadata must be inspected when acquiring the historical pinned version. No license is inferred for unrelated dataset/case sources solely from a dependency name.

Historical manifests retain source hashes, not a claim that excluded artifacts are present. SOURCE_TO_PUBLIC.json records original/public hashes; PUBLIC_MANIFEST.json identifies the current distribution. Sanitization changes path metadata and portable entry points but must not alter research equations or result values.
