# 同逐时算力输入补对照：独立审计通过

日期：2026-10-03 UTC。限定范围：原 alpha=100 kW、Q=600 kvar、n=160 服务见证，理想测量、10 kHz 二电平 PWM 仿真。核心理论、V1A、V2及其失败/通过记录均未改写。

## 为什么必须补对照

V2 的 F 支路在服务期保持 P=Pbase、Q=0、d=650 kW、uFeed=0；S 支路执行原 P/Q/d/u 计划。源码 `V2/recovery.cpp` 第41行确认 F 同时去掉了实际计算耗电脉冲。因此 F/S 的逐时任务输入不同。二者在0–0.2 s的总计算电能都为130 kJ，在0–0.9 s都为585 kJ，但服务中累计差最大10.5 kJ。电能总量相同不等于逐时任务输入相同，也不是实测 FLOP/job 等价。

旧 V2 仍有效地显示 S 返回基准物理轨道。旧恢复窗口0.2–0.7 s中两支路实际输入均为650 kW，所以旧恢复交换量本身有效；其进入恢复窗的状态来自不同前史。旧全过程 S−F 不能单独归因于相同任务输入下的网侧服务。

## 三支路与冻结

- F：不可修改的旧 V2 平坦负荷、无服务支路
- S：不可修改的旧 V2 服务支路
- L：新同负荷、无网侧服务支路。逐时 d_L(t)=d_S(t)；Q请求为0，uFeed为0，有功请求为 P_L=2d/(1+sqrt(1−4cd))，c=R/(1.5 Vp²)，其导数为 d_dot/sqrt(1−4cd)

L 使用声明模型的铜损补偿和原已授权已知负荷计划，不读取反事实支路、不读取未来实测负荷、不把实际 tau/ramp 送入控制器。各分支共享每个积分步长的2 s完整名义检查点、实际电网/载波时钟和V2控制/门控规则。已授权P/Q半拍预览可以使非PWM对齐的onset状态不同；成本从共同检查点另计，不假装onset状态相同。

独立检查代码 diff：只增加 L 的命令生成分支和模式选择；S/F命令路径、功率级方程、电流环、W+B外环、库存环及门控均未改。新可执行程序对两个冻结 V2 nominal S 运行的重算与旧 CSV、dense 数组和极值逐位一致。

新协议/源码/评估集合于任何 phase3 仿真前冻结；本独立评估器于看到 L 结果前冻结。全部17配置×2积分步长都是已出现参数的追溯对照，不能增加“新盲测”的样本数。新的34条验收行复用旧S/F、每行增加一个L支路。

## 独立原始数据复算

本审计未导入实现者的评估器，直接读取原始 NPZ/JSON、公共时间戳与里程碑快照。全部34条 S−L 比较通过预冻结标准：

|指标|全部34条最大值|预冻结限制|
|---|---:|---:|
|0.6–0.7 s公共1微秒网格的 W 差|0.226772043 J|2 J|
|同窗口 B 差|0.225669519 J|2 J|
|同窗口逐相电流差|0.000296729 A|2 A|
|0.2–0.7 s增量 cP 峰|27.822233 W|5000 W|
|恢复有符号电量绝对值|0.274866326 J|100 J|
|恢复正向电量|0.134570904 J|100 J|

有符号电量取物理功率积分及里程碑差；正向/绝对电量取匹配PWM周期平均功率差的对应积分。这三项不能相互替代。

L 自身通过硬界与跟踪检验：Vdc=1195.447108–1202.716454 V；相电流峰1150.088506 A、矢量峰1150.365964 A；圆形调制利用率≤0.85585243；B恒50 kJ、b=u=0。其20 ms均值有功/无功跟踪误差最高84.521 W/401.706 var，低于2 kW/10 kvar。它是可行的无服务负荷跟随对照，不是故意令恒功率无缓冲设备耗空直流电容的弱基线。

S/L相同输入由源代码函数定义逐时保证；公共PWM轨迹的累计计算能量数值差最大3.97675×10⁻⁷ J，低于冻结1e−5 J质量阈值。三支路612行窗口账本独立复算，有符号分解 S−F=(S−L)+(L−F) 的浮点结果残差为0；正向/绝对量分别直接积分，不使用这个线性分解。最大配对能量守恒残差6.70638×10⁻⁵ J，仅为仿真诊断精度。

## 归因改变了什么

名义细步长（0.5微秒）从共同检查点到0.9 s的总AC有符号增量：

- S−F = 134.679038310 J
- S−L = 69.002736744 J
- L−F = 65.676301566 J

因此约65.68 J属于相对平坦负荷的任务形状效应；相同逐时任务输入下、相对这个声明的负荷跟随策略，网侧服务的全过程净增量约69.00 J。该对照不是所有无服务控制器中的能量最优解，也未建立硬件因果收益。

全部34条的全过程 S−L：有符号增量68.964577–69.030096 J，正向交换14.248399–14.250724 kJ，绝对交换28.427833–28.432419 kJ。这些计划服务期的往返功率分配不属于0.2–0.7 s的100 J恢复预算。不能只报净69 J而遗漏大幅往返交换。

名义细步长的 S−L 恢复有符号/正向/绝对电量为−0.215298 J、0.042353 J、0.300004 J。全部配置0.7–0.9 s的后续有符号增量绝对值≤0.000236428 J，在声明观察窗内未见明显延后能量债务。

## 保留的边界

1. 原100 J核心容量合同仍是0–0.2 s理想平均模型的净晚段余量；本阶段100 J是另一个0.2–0.7 s恢复窗口交换预算。不能声称808–834.41453 kvar夹逼已经在PWM同合同验证
2. 本阶段只补原Q600内部见证的同负荷对照，未验证808边界或1050多周期恢复
3. 34行是17物理配置的双步长追溯检查；有限配置通过不保证整个参数盒鲁棒性
4. PWM硬界极值是数值采样检查，物理返回容差只检查W/B/相电流；不证明完整控制器状态精确返回、无限时轨道恢复或实物计量精度
5. 普通能量PI与负荷跟随铜损补偿不作为新控制算法；本阶段修复对照归因，并不另立原创性主张
