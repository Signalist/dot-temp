# G3 外生阶段波形：证据边界与下一协议建议

审阅日：2026-10-02 UTC。仅定向原始资料审阅与协议定义；未下载原始功率数据、未执行外部代码、未安装软件、未仿真。`paper_ready=false`。固定电网侧 BESS；内部 UPS/PSU 与工作负载均不受研究控制器调度。本文件不改变任何已锁定模型或轨迹。

## 1. 可立即采用的结论

- **可以增加非正弦外生阶段模板，但只能称“文献结构启发的公开合成波形”。** 尚没有足够证据把一个确定的幅值、同步比例和电气传递函数称为典型设施 PCC 波形。
- **公开原始功率遥测存在，公开可复现的毫秒级设施 PCC 故障波形尚未在这次定向审阅中确认。** MIT 的 GPU 100 ms 记录是前者，不能自动升级为后者；其论文还描述设施监测，不能反向断言 MIT 完全没有设施数据。
- 慢阶段有实际生产遥测支持；GPU 到 PSU 的缓冲有单工作站同步电气测量支持；完整设施链条的故障动态主要仍由通用 EMT 模型支持。三个证据层级不能相互替代。
- 单正弦保留为解析/模型负控制。任何新波形须先证明健康工况中存在满足服务、损耗补偿及所有硬约束的持续轨道，之后才有资格进入故障冲突研究。

## 3. 供电链必须显式区分的边界

以下是 G3 的建模要求和证据缺口清单，不声称从上述资料辨识出了目标设施。

1. **GPU/板级 → 服务器 PSU**：板级 DC 的变化不等于交流有功；应包含其他服务器部件、效率与内部储能。高频时电流幅值、瞬时 v·i、周波有功三个量不能混用。
2. **PSU/PFC/DC-link → UPS输出或机架母线**：正常电压下可用缩约滤波作假设；欠压时必须切换到经验证的限流、DC能量、保护动态。PFC的功率因数控制并不保证 PCC 的 Q 恒为零。普通电容 hold-up 也不是双向长期储能。
3. **UPS → 配电 → PCC**：固定拓扑、模式、限流、转移门槛/延迟和回接规律。控制器无内部 UPS 调用权限。如果引入 UPS 储能，必须有独立库存与功率边界，不能作为免费无限能量端口，也不能与电网侧 BESS 的能量重复记账。
4. **冷却及其他设施负荷**：单独的基线/动态项和电压响应。PUE 是能量口径，不是逐毫秒乘法滤波器。没有数据时不得把全部辅助负荷做成与 GPU 完全同相的比例副本。
5. **聚合**：真实同步比例、跨作业相位分布及测时偏差目前未知。可用预声明的外生 cohort 做敏感性，但不得通过选择 GPU 数量、复制同一条迹线或故障前重对齐把峰值“制造”成现场事实。

因此区分两个接口：`P_L^0(t), Q_L^0(t)` 是名义电压下外生需求；实际 `P_L,Q_L` 由同一电压依赖负荷律、供电链状态和保护产生。故障时不能继续强迫理想恒功率到 V→0，也不能把 nominal playback 当成已测故障响应。若保持内部任务时间不断，必须验证已有内部缓冲能够支持；否则此场景无依据。这里不授予任务暂停/重启控制权限。

## 4. 一个可公开重建的保守合成模板

### 4.1 定义与一个起始实例

取相位 `u=(t mod T)/T`；相位只给离线场景生成器和审计，不给控制器。定义四段名义形状：

| u 区间 | 离线描述 | g(u) |
|---|---|---:|
| [0,0.2) | 低功率同步段 | 0.5 |
| [0.2,0.4) | 高功率前向段 | 1.0 |
| [0.4,0.6) | 中等功率过渡段 | 0.75 |
| [0.6,1) | 高功率反向段，周期末下降 | 1.0 |

实例 `T=30 s`，段长 `6/6/6/12 s`，`g_bar=0.85`。这四个具体占空比和功率水平是**透明的研究设计值**，没有从现场曲线拟合。先不叠加短 notch、随机 burst 或 checkpoint 长中断，避免一次引入无法追溯的参数。

健康条件下以 `tau_e z_dot=g-z` 平滑阶跃，采用其稳定周期状态；`tau_e=10 ms` 是公开合成滤波选择。定义

`P_L^0(t) = P_bar + DeltaP_pp * (z(t) - g_bar)/0.5`。

这里 `DeltaP_pp` 是目标名义峰峰值参数；滤波后极值略收缩，实际峰峰值须记录。P_bar 是设施或试验负荷基数，**不从一张 GPU 曲线乘卡数获得**。首个诊断取 `Q_L^0=Q_bar`，其值应来自原协议；若设零，标为假设而非现场功率因数。该定义直接在所声明的聚合电气接口使用；不得又串联一个未经辨识的完整链条重复滤波。

“保守”指不过度声称现场真实性，并非对故障后最坏情况的数学支配保证。此模板尚未获得健康可行性或故障结果。

### 4.2 参数范围的证据标签

| 参数 | 可辩护起始范围/值 | 依据与限制 |
|---|---|---|
| 宏观周期 T | 20–60 s；实例30 s | 数十秒结构有 W1/W2 支持；20、60是研究括界，不是总体分位点 |
| 反向/前向时长比 | 起始固定2 | W1的近似结构；不声称所有模型/并行策略成立 |
| 各占空比、低/中/高比例 | 上述唯一实例 | 未标定；不做宽参数搜索来挑冲突 |
| 合成边沿 tau_e | 10 ms；必要消融2、5、10 ms | 与W1通用毫秒模型同量级；这是P参考滤波，不是复制其电流源/电阻模型，也不是现场传递函数 |
| 20–50 ms缓冲 | 只记为W3局部滞后证据 | 不能转换成tau_e或断言设施上下界；若将来测试只标未标定敏感性 |
| DeltaP_pp/P_bar | 起始0.05；候选0.02–0.10 | **人为温和诊断尺度，无现场统计背书**；还须服从锁定BESS功率、爬坡及健康可行门 |
| 相干负荷份额 alpha | 未知；若必要用0、0.25、0.5、1边界消融 | 纯结构性括界，不是实测分布；alpha=1只能称全相干压力场景 |
| PCC滤波、PUE动态、UPS门槛、Q律 | 未知 | 不给“典型”统一数值；定值不足时限制结论为声明过的合成电气负荷 |

若研究聚合，只可预先固定 `z_agg(t)=sum_k w_k z(t-delta_k)`、`sum w_k=1`，并保存所有权重和偏移。所有 `delta_k` 是场景外生常数，不可由研究控制器改动；聚合后也不得重新归一化到同样峰值来抹除去同步作用。完全相干与分散相位的比较应同时报告均值、峰峰值、爬坡和谱，而不是只报标签。

若下一阶段引入更快突发，须重新取得可解释的边沿分辨率或显式标为假设；不能从100 ms GPU采样插值出5 ms“测量”，也不能把W2的0.2–3 Hz频谱摘要合成为唯一真实波形。

## 5. 控制信息、等价性与健康准入门

### 因果信息接口

- BESS仅获当下可测量的 PCC 电压/电流/P/Q、自身电池/DC状态与因果历史；滤波器、状态估计和依据历史学习的预测须一视同仁。
- 不提供未来跌落/清除时间、外生文件未来样本、真相位、无噪声阶段标签、checkpoint预告或内部作业状态。固定、事先约定的并网功率/服务预算可为公共信息，不等于未来波形预览。
- 服务合同要明确：跟踪名义外生补偿指令，还是维持实际净并网功率。二者在欠压引起负荷降额时不等价，不能在结果出来后切换定义。
- 例如净并网服务中，BESS注入为正时，可用当前测得的 `P_L(t)-P_grid_contract` 形成请求；合同基线和损耗补偿由健康历史/事前协议确定，不能按将来故障调节。

### 工业等价对照

对“AI”和“工业”两个名字，若 `P_L^0/Q_L^0`、动态电压律、供电链/保护参数、内部初态、网络、BESS、控制测量和扰动完全相同，所有电气输出应在同样数值容差内一致。**这是必须通过的等价负控制。** 差异只允许来自有证据或明确假设标签的波形、聚合及供电链差异；标签本身不进入状态方程。相同P/Q轨迹但不同欠压律并非等价输入，不能据此归因于AI身份。

### 每条新波形先过的健康门

1. 不加故障，固定同一拓扑和真实损耗；建立完整持续轨道，包括BESS源动态、控制积分器、延迟、DC能量、SoC及已纳入的负荷/UPS状态。不得每周期或每相位重置状态。
2. 验证实际电流、调制、AC/DC电压、源功率/爬坡、SoC和服务约束逐时成立；只检查参考限幅或平均值不足。
3. 周期试验须有明确损耗补偿：全系统一个周期总输入等于负荷能量加损耗且储能库存闭合。若BESS持续对称零均值AC交换却未补偿损耗，不能声称SoC周期闭合。允许的额外净充电须在原服务合同内；否则健康目标不可行。
4. 先登记轨道收敛/闭合容差、保守误差界和能量残差，再开展故障。无法健康闭合的模板退回需求或模型讨论，不能在故障后包装成新服务冲突。
5. 故障时钟只抽取这条已合格轨道的完整状态；比较双方使用相同因果信息。恢复以正确外生时钟下的持续轨道为目标，不追逐静态定点，也不停止场景文件。

## 6. 数据复现的最小后续清单

仅在获准进入数据阶段后：从MIT发布入口取一个小型明确作业样本，记录对象路径、哈希、许可、字段、缺失/重复时间戳、GPU数量与时间对齐误差；先验证100 ms是记录间隔，独立刷新率另列未知。按原时间戳聚合全部被声明的测点，保留未观测CPU/网络/冷却/UPS项的缺口。不要下载整个TB级数据集或运行仓库脚本作为默认动作。

如要主张真实设施FRT适用性，仍需具有测点定义与时间同步的 PCC 三相电压电流/有功无功、IT/UPS侧功率和模式/保护记录，以及故障前健康段。100 ms功率轨迹本身无法辨识毫秒电压响应。当前正确对外定位：**具有生产现象依据的合成阶段扰动下，固定电网侧BESS的服务仲裁研究；尚非现场数据中心波形/故障复现。**
