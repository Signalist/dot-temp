## 与控制器无关的必要界

令 τ 为故障后时间，Imax 是实际持续电流上限 1 pu，不是 0.95 pu 电流参考上限，也不是 1.1 pu 紧急停止阈值。把全部允许电流都授予有功出口，并放宽无功服务、调制、延时及除斜率外的源动态限制。

锁定的三相串联 RL 模型给出

    W = Wdc + WL,
    WL = 3/4 (Lf+Lg) |i|²,
    dW/dτ = Pbus − Pideal_source − Pinverter_loss − Pcopper.

远端理想源、损耗及储能上界为

    Pideal_source ≤ ρ Sbase,  Sbase = 1200000 W,
    Pinverter_loss ≤ 7200 W,
    Pcopper ≤ 1.5 (Rf+Rg) Imax² = 23940.446282519868 W,
    Lloss = 31140.446282519868 W,
    Wdc,max = 26136 J,
    WL,max = 397.09750202003335 J,
    H = Wdc,max+WL,max−Wdc0−WL0 = 4341.250139445723 J.

此处 Pideal_source 是送入远端理想电压源的有功，不是 PCC 有功。允许 PCC 电压受线路、电感动态和控制作用影响；其所有动态储能已经通过完整 RL 电感能量计入。

源可双向运行，但最大向下斜率为 Rdown=5000000 W/s。正功率段效率 η=0.99，因此

    Pb(τ) ≥ Pb0−Rdown τ,
    Pbus(τ) ≥ η(Pb0−Rdown τ).

对所有预选的 150 ms 条件，右边源功率仍为正：Pb0/Rdown≈163.127935 ms，且 150 ms 时 Pb 下界约 65.639676 kW。因此本次不需要负功率分段；将来若越过零点，必须用 p<0 时的 p/η，不能把可充电源错误截断为零。

积分得到

    Fρ(τ) = aρ τ − 0.5 b τ²,
    aρ = η Pb0 − Lloss − ρ Sbase,
    b = η Rdown = 4950000 W/s.

若实际电流和 DC 电压在整个前缀都保持合规，则 W(τ)−W(0)≤H。因此

    M(ρ,T) = max(0≤τ≤T) Fρ(τ) − H > 0

足以排除所有持续电流合规策略的联合 DC 安全。最大值可直接计算：

    τpeak = clip(aρ/b, 0, T),
    Fmax = aρ τpeak − 0.5 b τpeak².

M=0 只是该松弛证据的等号，不能称严格矛盾；M<0 更不能证明存在可实现的安全策略。

## 近界点的预注册选择规则

定义 tc=sqrt(2H/b)。若 T≥tc，解析临界值为

    ac = sqrt(2 b H),
    ρc(T) = [η Pb0 − Lloss − ac]/Sbase.

若 T<tc，则需用 ac=H/T+0.5 b T，因为该时长的最大前缀出现在终点，而不是抛物线顶点。这一短时分支可用于审计其他时长，但本次不增加条件。

对固定 T=150 ms：

    tc = 41.8812662223 ms,
    ac = 207312.267800323 W,
    ρc = 0.4741921372499138 pu.

预选规则为：在 0.001 pu 的固定电压网格上，选严格高于 ρc 的首个点，ρnear=ceil(1000ρc)/1000。故唯一近界候选为 0.475 pu。规则只用解析必要界和共同初态，不依赖新控制器的运行结果。

0.475 pu 时 a=206342.832500219 W，τpeak=41.6854207071 ms；150 ms 终点下界却为 −24736.075125 J。必须用最大前缀，不能仅看故障清除时的能量。0.85/0.75 pu 均有 a<0，该过压必要界在整个区间不活跃，但无功、电流动态或其他限制仍可能造成失败。

## 外向舍入与敏感性审计

重新核对共同初态满足 Pb0≥815600 W、Wdc0≥21915 J、WL0≥276 J，并采用 Wdc,max≤26137 J、WL,max≤398 J、逆变损耗≤7200 W、铜损≤23941 W、源有功上界≤ρ×1200000+1 W。得到保守 H≤4344 J。

用同一前缀最大公式计算，0.85/0.75 的保守 M 为 −4344 J，0.475 的保守 M 为 −44.958060 J。故舍入不会把任何所选点错误标成“必要不可行”；它也没有替这些点提供可行证明。

在 0.475 处，局部 ∂M/∂ρ=−Sbase τpeak，约 −50022.5 J/pu；∂M/∂Pb0=ητpeak，约 0.04127 J/W。约 0.001 pu 的电压差或 1 kW 的初始源功率差就能改变约 50 J 或 41 J 的界值。这正是近界诊断的用途，不能把它包装成实机鲁棒可行边界。

## 声明范围与冻结纪律

- 控制器当前参考、候选 PCC 电压和故障后源命令均未被当成普遍物理限制
- 没有额外制动电阻、斩波器、额外储能、额外旁路/续流耗能通道、瞬时源断开或状态复位
- 未做新的 ODE 积分、控制器轨迹、参数搜索或性能比较
- 保留原资源和限值；若轨迹失败，报告发生的约束及先后顺序，不修改参数让它通过
- 这些条件是 Gate A 模型检查，不能据此宣布新控制器优于 MPC、振荡服务机制成立或 Gate B 获准
