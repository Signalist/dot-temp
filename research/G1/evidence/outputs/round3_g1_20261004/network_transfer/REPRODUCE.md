# Reproduction

Run from the workspace root. Python is outputs/round2_20261003/andes_env/bin/python. Set OPENBLAS_NUM_THREADS=1 and OMP_NUM_THREADS=1. No new packages are required. Do not redistribute the environment. Round2 scientific files and simulator sources remain read-only.

1. Development: design_controller.py reproduces the sparse11-phase experiments; evaluate_development.py reproduces the rejected unseen-command-cap failure. design_binned.py reproduces the tighter.0915 Hz development sensitivity. These are retained diagnostics, not the final controller.
2. Final common-margin controller coefficients: run design_binned93.py. It solves all50 observation-bin representatives at the common.093 Hz midpoint target, refining violated.02 s output constraints. It writes four binned93_*.npz files. The saved frozen hashes identify the actually confirmed coefficients; LP degeneracy/software versions can change other optimal coefficient choices, so do not silently relabel a regenerated alternative as the same frozen controller.
3. Run audit_exact_boundaries.py for the exact rational parser and one-sided sample-boundary tests. Then run phase_lipschitz.py and certify_binned.py to recompute the analytic all-phase/all-future LTI envelopes and exact physical checks. These are floating-point analytic bounds, not interval arithmetic.
4. Run openloop_continuous_lower.py --h .02, then --h .01, to reproduce the terminal-free continuous-measurable-input lower relaxations and their dual residuals. Their failure to separate the94.265 MWs upper is part of the result.
5. Inspect the saved HOLDOUT_PLAN.json and CONFIRMATION_FREEZE.json. freeze_confirmation.py refuses at its first main entry, before creating directories or generating any inputs, when a freeze exists. test_freeze_refusal.py verifies this rerun refusal leaves all78 frozen inputs, manifests and coefficient files unchanged in SHA-256, size and modification time. The original utility source pinned by the freeze hash is retained, byte-identical, in provenance/freeze_confirmation_at_v1_freeze.py; do not run that archival snapshot. REPRODUCIBILITY_GUARD_HARDENING.json records the current wrapper repair without changing the frozen manifest. Reproducing a new freeze requires a distinct directory/version. Confirmation schedules and measurement records are fully retained; there is no need to regenerate or rewrite them to replay the saved result.
6. Run run_confirmation.py --start 0 --stop 22 to replay the22 predeclared cases. It resumes verified successful same-hash outputs and refuses mismatched labels. The runner disables bytecode generation, clones only the small generated ANDES cache into this new round3 directory, resets HOME/MPLCONFIGDIR after importing the unchanged round2 adapter, and verifies the active pycode path is isolated. No simulator environment, source patch, or benchmark workbook modification is used.
7. The separately frozen outcome-informed amplitude challenge is AMPLITUDE_STRESS_ADDENDUM_FREEZE.json. run_amplitude_addendum.py without --freeze replays its saved +10% coarse/fine cases. It must not be merged into the original22-case holdout count.
8. Run collect_results.py to reconstruct exact linear responses to the identical canonical inputs, collect nonlinear endpoints, and recheck all266 locked round2/source/cache files. It produces NONLINEAR_CONFIRMATION_SUMMARY.json/.csv and ROUND2_INTEGRITY_CHECK.json. Addendum results remain separate.
9. Run make_figures.py for the scientific PNG/SVG figure. Its final amplitude panel requires the separate +10% result.

All paths are relative to outputs/round3_g1_20261004/network_transfer unless stated otherwise. The direct source model is the qualified round2/grid_transfer/kundur_reduced51.npz, pinned by SHA-256 in CONFIRMATION_FREEZE.json. Full raw per-case observables, canonical load and actual-power schedules, observation records, and fixed-policy coefficients are retained. Compressed nonlinear traces include individual generator frequency, COI, voltage, angle, branch P/Q, and input values, rather than unnecessary duplicated simulator state/environment trees. Original upstream licensing is preserved in round2/grid_transfer/ANDES_LICENSE_GPL3.txt.

The full test count is22 original confirmation runs plus2 separately frozen amplitude-follow-on runs. These include numerical repeats and stresses and are not independent statistical trials. Frequency acceptance, physical feasibility, LTI analytic certification, exact recovery, and nonlinear finite replay are separate checks.

Run audit_serialized_inputs.py to re-integrate the actual12-significant-digit replay CSVs without overwriting model-array metrics. SERIALIZED_INPUT_NUMERICAL_AUDIT.json declares command tolerance1e-9 MW and terminal SOC recovery tolerance1e-8 MWs. The final summary JSON explicitly distinguishes these serialized-input audits from the original model-array metrics.
