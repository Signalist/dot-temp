# Publication and preservation notes

This public branch contains only the G1 route, with no unrelated GFM surrogate project. No credentials, authentication metadata, email addresses identifying the user, private notes, upload receipts, or proprietary operational data were intentionally included.

Absolute execution-root references and runtime binary locations were made portable. `SOURCE_PROVENANCE.json` records original and public SHA-256 for every recovered file. The two package-level manifests were regenerated to validate the public derivative. Historical scientific manifests were retained as provenance; their old hashes are not falsely represented as new freeze identities. Numeric arrays, canonical input CSVs, controller coefficients and claims/negative results are unchanged.

Do not run archival synthesis, collectors, sealers or freeze generators over this evidence. Use a new disposable copy or a versioned experiment tree. Preserved scripts include rejected experiments; inclusion is not endorsement of their scientific premise.

Release boundaries: the compact archive did not contain 41 original raw trace arrays or the full old simulator/source tree. Public provenance records name the missing dependencies and exact hashes. The safe saved-evidence replay is substantially narrower than full nonlinear regeneration. No inaccessible input was replaced silently.

Original research-code reuse terms need an explicit owner/repository license; upstream GPLv3 notices are retained. This is not a new license grant. No external full-text papers or data-provider account access are distributed.
