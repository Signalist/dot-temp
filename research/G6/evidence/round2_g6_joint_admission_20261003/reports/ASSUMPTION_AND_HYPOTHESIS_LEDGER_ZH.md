# G6 假设、量词与候选账本

日期：2026-10-03。仅原顺序第6项G6；不改写已冻结G2时钟、G3服务、G4辨识或G5保真度结果。

## 1. 研究对象和容量单位

本轮主要变量a是既定工作点周围的负荷波形幅值/调制预算，不是新增平均MW、额定算力、完成任务数或吞吐。每块保持电气状态，不从零重新开始。工作量相同需要明确的线性功率—处理速率合同；零均值功率只自动保证相同块能量。

基本物理合同为P_i(kT+t)=Pbar_i+s_k b_ki q_i(t)，其中q_i为固定、有界、零积分模板。非负功率要求Pbar_i≥a_i||q_i||∞。若w_i=wbar_i+kappa_i(P_i−Pbar_i)，且wbar_i≥|kappa_i|a_i||q_i||∞，则每块完成wbar_iT工作，耗能Pbar_iT。本轮没有实测该处理速率关系。

正基值Kundur新增工作点单独重建，不能把这些Pbar条件加到旧矩阵后继续沿用旧A。旧公共网络结果先解释为有符号增量端口响应，具体基值审查见迁移材料。

## 2. 四类合同不是同一个问题

| 合同 | 幅值选择 | 相位/符号 | 是否普通按需幅值容量 | 同一二维模型的精确量 |
|---|---|---|---|---|
| 固定队列/固定模板群 | a全程固定 | 每块一个共同s_k | 否，删掉一个端口可能破坏抵消 | F(a) |
| 可选但固定的接纳组合 | 对每个b∈[0,a]验证；b选择后全程固定 | 每块共同s_k | 只覆盖一次选择的部分使用 | max{c1a1,c2a2,F(a)} |
| 动态可选幅值 | 每块独立选b_k∈[0,a] | 每块共同s_k | 是，仍需兑现共同阶段合同 | H(a)=[F(a)+c1a1+c2a2]/2 |
| 独立端口符号 | 每端口每块独立正负/降幅 | 不要求共同s_k | 更大的输入类 | c1a1+c2a2 |

这些合同在所声明仿真中均有相同块平均功率和条件工作量。共同阶段/模板是额外已保证信息，不是从当前相关性推断未来。动态可选幅值比固定模板更真实，但仍非任意实际PCC轨迹。候选和成熟支撑基线获取完全相同合同。

## 3. 核心假设及后果

| 项目 | 本轮采用 | 可推出 | 不能推出 |
|---|---|---|---|
| 电气动力学 | 主定理x+=rRθx+s_kb_k，0<r<1 | 无限块、携带状态的精确输出支撑 | 一般多模态AC系统同一几何定理 |
| 初态 | 偏差x0=0；单列任意初态反例 | 有限前缀单调到无限支撑 | 驻态安全足以覆盖任意启动 |
| 保护输出 | 核心定理块端C=(1,0) | 样本时刻幅值接纳域 | 块内连续安全 |
| 块内保护 | 公共模型另用相位支撑、导数插值界和模态尾界 | 所声明固定线性模型的连续时间数值夹逼 | 核心算术复杂度不加证明地迁移到sup_t之后 |
| 参数 | θ在定理中精确、固定；另设共享固定区间诊断 | 有条件实例复杂度；保留共同量词 | 从浮点估计判断无限Diophantine类型 |
| 参数不确定 | 同一个κ被所有端口和所有时刻共享 | supκ放在完整历史支撑外 | 每端口或每步重新挑κ仍是原题 |
| 控制权限 | 主要结果是给定合同下所有外扰序列 | 全输入鲁棒接纳 | 已设计可执行调度或失约回退控制器 |
| 电池/缓冲 | 主模型没有专设储能 | 没有虚构供能或跨块能量清零 | 储能能量可用收缩泄漏替代；平均平衡足够 |
| 随机模型 | 独立或有统一正转移概率的有限模式 | 特定初态条件下永久机会域退化为鲁棒域 | 任意控制/非全支撑过程没有机会收益 |
| 工作合同 | 明确条件仿射功率—工作关系 | 相同块工作/能量、相同截止块端 | 实际AI任务吞吐已验证 |
| 网络迁移 | 既有经审计Kundur/WECC，及新正基值Kundur | 条件模型、实现核对、有限NL轨迹 | 实测PCC校准或整个非线性输入族保证 |
| 数值界 | 几何尾和、Lipschitz公式；普通浮点评价 | 有显式截断/插值误差账本的数值界 | 已有全局向外舍入、特征分解残差证明 |
| 表示类别 | 原容量平面的直接多面体/分段线性gauge | ε所需线性片段/半空间数下界 | 任意提升LP、SOC、IQC、神经网络或算法运行时间下界 |

## 4. 候选逐项处置

| 候选 | 结果 | 原创/方法归属 |
|---|---|---|
| 无限块支撑、不变集合、自动机DP | 建立并与穷举核对 | 成熟方法；不列新算法 |
| F级数、有理角精确折叠、无理角非多面体 | 精确证明和复核 | Duda 2007/2008逐式先例 |
| 指数算术类型β与Θ(log1/ε)充要分型 | 完整证明，独立审查通过 | 本轮窄理论候选；定向查新未定位完整同题定理，未认证原创 |
| 固定可选接纳的r=1/2遮蔽阈值 | 严格边界和有理算术例证通过 | 窄结构候选；不推广到动态降幅 |
| 动态可选幅值H=(F+L)/2 | 几何、穷举、独立实现一致 | 初等六边形支撑恒等式；用于正确接纳语义 |
| 永久机会域与鲁棒域 | 证明及精确模式枚举通过 | 经典递归/模式等待结论，不列新概率理论 |
| 共同静态参数与切换参数差别 | 冻结41条射线均出现严格数值差 | 正确量词与成熟鲁棒化；不是算法增益 |
| 公共网络相关结构收益 | 同信息支撑完全重现，给出有限违约词 | 合同信息收益，不是新求解器 |
| 正算力基值工作点 | 另立预声明核验，不沿用旧A | 用于收回物理解释，不能升级为现场校准 |

## 5. 停止和保留原则

有实质新窄定理时，不因没有实测联合PCC而直接否定理论研究。但也不因数学证明完整就宣称重大算力物理创新或投稿成功。保留定理候选与可复现实验；公开介绍必须同时给出最接近逐式先例、表示类别、参数精确性、连续时间限制和同信息基线。

本轮不靠进一步缩角区间、挑射线、改变平均工作量或给候选额外控制权限制造增益。若NL边界不转移，保留原判定并报告差异。后续投入应围绕明确未闭合的机制或信息合同，而不是重复包装本轮经典基线。
